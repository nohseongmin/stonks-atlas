# 사전등록 — #44 한국 실적발표 후 표류(PEAD)

**작성 시각: 데이터 수집 전, 결과 보기 전.**

## 왜 이것만 남았나

데이터 축이 전부 소진됐는데 **하나가 남아 있다.**

| 축 | 검정 | 시장 |
|---|---|---|
| OHLCV | #2 #5 #7~#11 #14~#16, 카탈로그 224건 | 미국·한국·크립토 |
| SEC 재무제표 397만건 | #3 #17 | **미국만** |
| SEC Form 4 내부자 152만건 | #18 | **미국만** |
| FRED 금리·거시 | #13 #31 | 미국만 |
| **한국 기업 이벤트** | **없음** | — |

**한국 이벤트 데이터는 한 번도 안 썼다.** DART(금융감독원 전자공시)가
무료 공개 API 를 제공하므로 검정 가능하다.

## 확인한 것 (수집 전 실사)

| 항목 | 결과 |
|---|---|
| 비용 | 무료. 일일 20,000 건 |
| **접수일자 `rcept_dt`** | **있다** — 이게 없었으면 시작도 안 했다 |
| 종목 매칭 | 공시검색 응답에 `stock_code` → 기존 한국 243 종목과 직접 조인 |
| 배치 | 다중회사 주요계정 **1회 100 개사** → 전체 수집 수백 건 |
| 재무 데이터 시작 | **2015 년** |

## 검정 설계

**신호: SUE(Standardized Unexpected Earnings), 계절 랜덤워크.**

```
서프라이즈_q = 순이익_q − 순이익_(q−4)          ← 전년 동기 대비
SUE_q       = 서프라이즈_q / stdev(과거 8분기 서프라이즈)
```

**보유 규칙:** 발표일(`rcept_dt`)로부터 **1~60 거래일** 사이인 종목만 후보로 두고,
그중 SUE 상위 20% 를 균등 보유. 기존 `cross_section` 실행 종류로 표현되므로
**새 실행 종류를 만들지 않는다.**

## 미리 선언하는 것

**1. 애널리스트 컨센서스가 없다.** DART 는 공시 저장소이지 데이터 벤더가 아니다.
그래서 "예상 대비" 서프라이즈를 못 만들고 **자기 과거 대비**로 만든다.
이건 Foster(1977)·Bernard-Thomas(1989)의 **원형 방식**이라 정통이지만,
**컨센서스 기반 PEAD 와 같은 물건이 아니다.** 결과를 그렇게 부르지 않는다.

**2. 한국은 발표 순서가 미국과 다르다.** 미국은 어닝콜이 먼저고 10-Q 가 나중이지만,
한국은 **영업(잠정)실적 공시가 먼저** 나오고 분기보고서가 나중이다.
분기보고서 `rcept_dt` 를 이벤트일로 쓰면 **정보가 시장에 나온 날보다 늦다** —
룩어헤드는 아니지만(보수적) **진짜 표류 구간을 놓친다.**

따라서 **잠정실적 공시를 우선 이벤트일로 쓰고**(`report_nm` 에 "잠정" 포함),
없으면 분기보고서로 대체한다. **어느 쪽을 썼는지 종목·분기별로 기록**하고
결과에 비율을 보고한다.

**3. 창이 2016~2026 이다.** 재무가 2015 부터라 전년 동기 비교로 첫 해가 날아간다.
게다가 SUE 표준화에 과거 8 분기가 필요해 실질 시작은 **2018** 이다.
**약 8 년 · 32 분기** — 이 프로젝트에서 가장 짧은 창이다. 그렇게 적어둔다.

**4. API 키는 사용자가 발급한다.** `.env` 의 `DART_API_KEY` 로만 읽는다.
가입·인증은 사용자 계정 행위이므로 내가 대신 하지 않는다.

**5. 시행 수 1 건.** 파라미터(60 거래일 창, 8 분기 표준화, 상위 20%)는
PEAD 문헌의 관용값이고 **재탐색하지 않는다.** 안 되면 안 되는 것으로 적는다.

## 예상 (틀려도 그대로 둔다)

**벤치 미달로 본다.** 근거 셋:

1. **PEAD 는 가장 많이 발표된 아노말리 중 하나**이고 전 세계적으로 소멸 추세다
2. #42 에서 한국 저위험 엣지가 **2015 년에 죽었다**는 걸 확인했는데,
   DART 창이 정확히 2015~ 라 **겹치는 구간이 이미 죽은 구간**이다
3. 회전율이 높다 — 분기마다 포트폴리오가 갈리므로 한국 왕복 35bp 가 누적된다

**다만 이 검정은 처음부터 최근 레짐에서만 돈다.** #42 의 교훈("전 표본 통계는
사라진 엣지를 살아 있는 것처럼 보여준다")이 여기선 구조적으로 적용되지 않는다.
