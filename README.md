## 살아남은 것 — **없다**

마지막 후보였던 `mean-rev 딥바잉`도 배터리에서 죽었다.

```
무위험 4%    Sharpe +0.74 · 연복리  +5.2%
무위험 0%    Sharpe +0.19 · 연복리  +1.1%      <- 신호 자체가 내는 값
매수보유      Sharpe +0.65 · 연복리 +10.8%
```

**99% 를 현금으로 있는 전략이었다.** Sharpe 우위는 이자가 만들었고,
연복리는 13 자산 중 12 개에서 매수보유보다 낮았다.
"노출조정 알파 +3.5%" 는 **노출당 단위 값**이지 굴릴 수 있는 수익이 아니었다.

```
누적 619 시행 · 관문 통과 0 · 배터리 완주 0 · 매수보유를 이긴 신호 0
```

## 확립된 사실 — 전략과 무관하게 재사용 가능

### 비용이 모든 것을 결정한다

| | |
|---|---|
| 인트라데이 | **전 방식 전멸** (미장 t −2~−63, 코인 필요승률 >100%) |
| 회전율 vs 알파 | Alpha101 이 1 일 보유에서 −0.37, 21 일에서 +0.48. **알파가 아니라 회전율이 부호를 정한다** |
| 손익분기 | **레버리지로 못 낮춘다.** 수익과 수수료가 똑같이 배가 된다 |

### 수학적 상한

```
CAGR − rf = S·σ − σ²/2  는 σ = S 에서 최대,  그 값이  rf + S²/2
```

| 관측 최고 Sharpe | 절반켈리 월 | 3,000 만원 기준 |
|---:|---:|---:|
| 1.06 (코인 조합) | 3.21% | 96 만원 |
| 0.90 (BTC 매수보유) | 2.49% | 75 만원 |
| 0.50 (보수적) | 1.05% | 32 만원 |

**월 5% 에 필요한 Sharpe 는 1.42.** 610 시행 최고가 1.55 인데 그건 배터리에서 죽었다.

### 다중검정이 카탈로그를 스스로 죽인다

```
코인 시행    5 →  34 →  54 → 109 → 119 → 130
잡음바닥   1.15 → 1.55 → 1.80 → 1.91 → 1.94 → 1.98
```

**전략을 더 태울수록 통과 기준이 올라간다.** 130 시행 시점에서 통과하려면
Sharpe 1.98 이 필요한데, 외부 실증 최고가 1.04 였다.
