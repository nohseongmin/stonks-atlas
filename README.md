# dumpItAll

코인 무기한선물 레버리지 단타 — **$100 자본으로 가능한가**를 산술과 데이터로 답한다.

## 규칙

앞선 두 프로젝트에서 같은 방식으로 죽었다.

- **STONKS-03** — 480 시행, 관문 통과 0. 인트라데이 전략 전멸. 원인은 신호가 아니라 회전율.
- **AI_STONKS v2** — 급등주 ORB. 5 겹 가짜 엣지(생존편향·룩어헤드·소표본)를 벗겨내니
  −22.2bp, t=−15.96. 돈 넣기 전에 진실에 도달했다.

그래서 순서를 뒤집는다. **비용 산술이 먼저, 전략은 나중.**

```bash
python -m dump.costs
```

이걸 통과 못 하는 전략은 코딩하지 않는다.

## 이미 확정된 것

**1. 손익분기 가격변동은 레버리지와 무관하다.**

레버리지는 수익과 수수료를 똑같이 배로 만든다. 왕복 `2f + s` 를 넘어야 하는 건
1 배든 50 배든 같다. **레버리지는 손익분기를 낮추지 않는다.**

**2. 레버리지가 진짜 바꾸는 것은 파산 속도다.**

L=20 이면 왕복 한 번에 자기 자본의 2.2% 가 나간다. 엣지가 정확히 0 이어도
하루 10 회 왕복하면 **21 일 만에 −99%** 다.

**3. 수익 상한은 레버리지로 못 넘는다.**

`CAGR − rf = S·σ − σ²/2` 는 `σ = S` 에서 최대이고 그 값이 `S²/2` 다.
Sharpe 가 1.0 이면 어떤 레버리지를 써도 연 54% 가 천장이다.
