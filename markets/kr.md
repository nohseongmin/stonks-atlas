## 국장의 구조적 한계 — **고칠 수 없다**

### ① 시점정합 유니버스가 불가능하다

토스는 상폐 종목의 **메타데이터는 주지만 캔들을 안 준다**(6/6 HTTPError 확인).
16 년 창에서 **상폐가 통째로 빠져 있다.**

그 편향의 크기를 크립토(시점정합 가능한 유일한 시장)에서 **직접 쟀다**:

```
생존편향이 Sharpe 를 평균 +0.102, 연복리를 +5.97%p 부풀린다
모델마다 다르다: 장기반전_5년 +0.48(최대) ↔ 하방편차 −0.00(없음)
```

### ② 파생상품이 없다

국내 거래소(업비트·빗썸·코인원·코빗) **레버리지/파생 제공 0 개.**
공매도도 개인에게 사실상 닫혀 있다. **롱온리만 가능**하다.

## 미완 — 한국 PEAD (DART)

`STONKS-03` 에 코드·사전등록·테스트가 전부 완성돼 있고 **API 키 하나만 남았다.**

| | |
|---|---|
| 신호 | SUE = `(NI_q − NI_{q−4}) / stdev(직전 8 분기 서프라이즈)` |
| 이벤트일 | **`rcept_dt`(접수일)** — 회계기간을 쓰면 한 달짜리 룩어헤드 |
| 보유 | 60 일 |
| 상태 | **미검정.** `https://opendart.fss.or.kr` 무료 키 발급 후 `python -m stonks.dart` |

**가격이 아닌 데이터를 쓰는 유일한 미검정 축**이다.
